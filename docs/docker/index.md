## 基础概念（先理解这些再动手）

| 概念            | 前端类比                               | 作用                        |
| --------------- | -------------------------------------- | --------------------------- |
| 镜像(Image)     | 前端项目的 node_modules                | 只读模板，包含运行环境+代码 |
| 容器(Container) | 正在运行的开发服务器（如 npm run dev） | 镜像的运行实例              |
| Dockerfile      | 项目的 package.json                    | 定义如何构建镜像的"配方"    |
