# Mongoose 文档

Mongoose 是一个基于 Node.js 的 MongoDB ODM（对象文档模型）库，提供了强大的数据建模和验证功能。

## 简介

Mongoose 让你可以用更结构化的方式操作 MongoDB 数据库，支持数据验证、查询构建、业务逻辑钩子等。
