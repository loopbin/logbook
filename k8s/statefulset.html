StatefulSet 配置详解

概述

StatefulSet 是 Kubernetes 中用于管理有状态应用的工作负载资源，提供稳定的网络标识、持久化存储和有序部署/删除。

基础 StatefulSet 配置

1. 简单 StatefulSet

apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: mysql
  namespace: default
spec:
  serviceName: mysql
  replicas: 3
  selector:
    matchLabels:
      app: mysql
  template:
    metadata:
      labels:
        app: mysql
    spec:
      containers:
        - name: mysql
          image: mysql:8.0
          ports:
            - containerPort: 3306
          env:
            - name: MYSQL_ROOT_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: mysql-secret
                  key: root-password
          volumeMounts:
            - name: mysql-data
              mountPath: /var/lib/mysql
  volumeClaimTemplates:
    - metadata:
        name: mysql-data
      spec:
        accessModes: ["ReadWriteOnce"]
        resources:
          requests:
            storage: 10Gi

高级配置

1. 有序部署和删除

apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: my-app
spec:
  serviceName: my-app
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
        - name: my-app
          image: nginx:1.20
          ports:
            - containerPort: 80
          env:
            - name: POD_NAME
              valueFrom:
                fieldRef:
                  fieldPath: metadata.name
            - name: POD_NAMESPACE
              valueFrom:
                fieldRef:
                  fieldPath: metadata.namespace
  podManagementPolicy: OrderedReady

2. 并行部署

apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: my-app
spec:
  serviceName: my-app
  replicas: 3
  podManagementPolicy: Parallel
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
        - name: my-app
          image: nginx:1.20
          ports:
            - containerPort: 80

3. 更新策略

apiVersion: apps/v1
kind: StatefulSet

  name: my-app
spec:
  serviceName: my-app
  replicas: 3
  updateStrategy:
    type: RollingUpdate
    rollingUpdate:
      partition: 0
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
        - name: my-app
          image: nginx:1.20
          ports:
            - containerPort: 80

存储配置

1. 持久化存储

apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: mysql
spec:
  serviceName: mysql
  replicas: 3
  selector:
    matchLabels:
      app: mysql
  template:
    metadata:
      labels:
        app: mysql
    spec:
      containers:
        - name: mysql
          image: mysql:8.0
          ports:
            - containerPort: 3306
          env:
            - name: MYSQL_ROOT_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: mysql-secret
                  key: root-password
          volumeMounts:
            - name: mysql-data
              mountPath: /var/lib/mysql
            - name: mysql-config
              mountPath: /etc/mysql/conf.d
      volumes:
        - name: mysql-config
          configMap:
            name: mysql-config
  volumeClaimTemplates:
    - metadata:
        name: mysql-data
      spec:
        accessModes: ["ReadWriteOnce"]
        storageClassName: "fast-ssd"
        resources:
          requests:
            storage: 10Gi

2. 共享存储

  serviceName: my-app
  replicas: 3

    matchLabels:
      app: my-app

      labels:
        app: my-app

      containers:
        - name: my-app
          image: nginx:1.20
          ports:
            - containerPort: 80
          volumeMounts:
            - name: shared-data
              mountPath: /shared
      volumes:
        - name: shared-data
          persistentVolumeClaim:
            claimName: shared-pvc

常用命令

查看 StatefulSet

# 列出所有 StatefulSet
kubectl get statefulsets

# 查看特定 StatefulSet
kubectl get statefulset my-app

# 查看 StatefulSet 详情
kubectl describe statefulset my-app

# 查看 Pod 状态
kubectl get pods -l app=my-app

管理 StatefulSet

# 创建 StatefulSet
kubectl create -f statefulset.yaml

# 应用配置
kubectl apply -f statefulset.yaml

# 删除 StatefulSet
kubectl delete statefulset my-app

# 编辑 StatefulSet
kubectl edit statefulset my-app

调试 StatefulSet

# 查看 Pod 日志
kubectl logs my-app-0

# 进入 Pod
kubectl exec -it my-app-0 -- /bin/bash

# 查看存储卷
kubectl get pvc

# 查看存储卷详情
kubectl describe pvc mysql-data-my-app-0

最佳实践

  1. 存储管理：使用持久化存储卷
  2. 网络配置：使用 Headless Service
  3. 有序操作：理解有序部署和删除的影响
  4. 监控告警：监控 StatefulSet 状态
  5. 备份恢复：定期备份有状态数据
  6. 安全配置：实施适当的安全策略
  7. 资源管理：合理配置资源限制
